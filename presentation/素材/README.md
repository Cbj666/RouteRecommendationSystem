# 素材：地图几何层（透明底 PNG）

生成脚本：`build/make_geometry_assets.py`（重跑一次约 30 s：读数据 → 算路线 → 出 15 张图）

所有图都是**透明背景**，可以直接拖进 PPT，底面放色块、上面叠线；也可以叠在一起用。
分三套配准范围，**同一套内部的图片尺寸完全一致**，在 PPT 里设成同样宽高就能严丝合缝对齐。

## 配色与改色

主色 `#15503C`（深墨绿），浅色 `#7FA894`，填充 `#D9E8DF`。
透明底的纯色线条在 PPT 里选中图片 →「图片格式 → 颜色 → 重新着色」可以整体换色；
若要控制精度，直接改脚本顶部的 `PRIMARY` / `ROCK` / `PALE` 后重跑。

## 数据口径

- 路网：`data/processed/running/v1/segments.gpkg`（91,203 段，EPSG:32650 计算长度）
- 行政区：`data/processed/v1/wuhan_boundary.geojson`（WGS84）
- 路线：`app.running.generate_loops()`（环线 / 马拉松）与距离环带 + 偏好代价（单行线），起点 114.3547, 30.5342
- 热点：`data/output/running/v1/demo/hotspots.csv`（55 个起点 × 前三条 5 km 环线均分 34.4–74.1）

## F 套 · 六边形热力（新增）

半径 1.4 km 的蜂窝格，只保留市域内且 9 km 内有样本的格，共 **264 格**；每格的值是 55 个起点的前三环线均分做反距离平方加权（IDW）的结果。

| 文件 | 内容 |
|---|---|
| `F1_热力六边形_全市.png` | 只有热力斑块 |
| `F2_热力六边形_带边界.png` | 斑块 + 市界 |
| `F3_热力六边形_带路网.png` | 斑块 + 浅灰路网 + 市界 |

> 说明：IDW 是**插值**结果，斑块颜色表示「这一带大概率跑得舒服」，不代表实测；越远离样本点越不可信，所以只在 9 km 内成图。
