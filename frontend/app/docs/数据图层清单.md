> 检测时间：2026-11-17；检测范围：`data/processed`、`data/output/running/v1`、`data/output/ui` 下的
> `.geojson` / `.gpkg` / 可渲染 `.csv`。坐标系全部为 **WGS84 (EPSG:4326)**。
>
> 结论：共检测到 **16 个空间数据文件** = **8 个 GeoJSON**（7 个渲染数据源 + 1 个 demo 环线）

## 3. 复现与校验

```powershell
cd frontend/app
npm run sync:geo        # 重新生成 public/geo/*.geojson 与 manifest.json（predev/prebuild 自动执行）
node scripts/ui-smoke.mjs   # 需先 npm run preview，见 README
```

- `public/geo/` 是 **gitignored** 生成目录：`data/` 是唯一数据源，换数据后重跑 `npm run sync:geo` 即可。
- `manifest.json` 同时记录 `inventory`（16 个文件的路径、格式、要素数、bbox、对应渲染图层），
  页面图层面板头部的「16 个空间文件 · 13 个图层」即来自 `summary`。
- 检测口径：GeoJSON 用 `features.length` 与坐标范围求 bbox；GPKG 用
  `pyogrio.read_info()`（Python 3.13 + geopandas 1.2.0，见 `data/output/ui/m3-data-scan.json`）；
  CSV 用行数。坐标统一 WGS84。
