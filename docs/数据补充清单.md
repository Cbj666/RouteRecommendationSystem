## 二、需要你做的（很少，按优先级）

### 1. 必须：确认百度 AK 的全景权限（只有做"绿视率"才需要）

答辩里如果只想讲"绿地距离代理"，**这一步可以跳过**。
如果要一个真正的亮点（街景绿视率，比绿地距离可信得多）：

1. 登录 <https://lbsyun.baidu.com/> → 控制台 → 应用管理 → 你的应用；
2. 看"全景静态图 API"是否已开通（个人认证账号一般可以申请，有日配额）；
3. 开通后告诉我，我用 `.env` 里现有的 `BAIDU_SERVER_AK` 抽样采集，
   每个路段每 100 m 取一张街景，做绿视率估计（只算绿色像素占比，够用）。

**代价**：配额有限，只能抽样（例如 2,000 个路段点），不能全城。

### 2. 建议：官方全民健身设施点位

OSM 的 `leisure=pitch` 在武汉只有 2,608 个，且远城区稀疏。
如果你能从下面任一渠道拿到官方点位（Excel/CSV 都行），设施维度会立刻权威很多：

- 武汉市体育局 / 各区文旅局网站的"全民健身设施""健身步道"公示；
- 武汉市公共数据开放平台（搜索"体育设施""健身路径"）；
- 学校图书馆/指导老师如果与规划院有合作，直接要一份 `shp`。

放到 `data/raw/official/` 即可（目录我已建好说明）。

### 3. 可选：官方绿道 / 慢行系统规划

武汉市园林和林业局的"绿道规划图"通常是 PDF 或图片。若能拿到矢量（shp/geojson），
可以做一个"我们的评分 vs 官方规划的绿道"对照图，答辩很有说服力。
拿不到也不影响主线。

### 4. 可选：更高精度 DEM（一般不做）

1:1 万 DEM 或 5 m DEM 需要测绘资质申请，周期长。SRTM 30 m 对"坡度排序"够用。

## 三、明确补不来的（要在报告里写成限制，不要硬做）

以下都实测过了，不是"没找"，是数据本身不存在或覆盖太低：

| 想要的字段 | 实测覆盖 | 结论 |
|---|---|---|
| `surface`（路面材质） | 4.3%（4,216 / 98,939 条路） | 做不了，用道路等级代理 |
| `lit`（照明） | 0.9% | 做不了，不评价夜跑 |
| `sidewalk`（人行道） | 0.2% | 做不了 |
| `maxspeed`（限速） | 1.2%（且 Geofabrik 用 `0` 表示缺失，98.9% 是 0） | 不能当速度用 |
| 路段车流量 | 无公开数据 | 用等级 + 交叉口密度 + 距主干道距离代理 |
| 街树 `natural=tree` | 3,635 个节点 | 只能做展示图层，不能当绿荫度量 |
| 真实跑步轨迹（Strava 等） | 无公开接口 | 不做行为验证，明确说明 |
| 噪声 | 无 | 不做 |

## 五、拿不到数据时的说法（答辩口径）

> 城市慢跑环境评价的真实痛点是没有"人"的数据：没有真实跑步轨迹、没有路段流量、
> 没有街景绿量。我们用三条可获取的公开数据（OSM 路网与设施、SRTM 地形、
> 官方统计/POI）构建了代理指标，并明确标注了每个指标的代理性质与误差方向。
> 这不是数据的缺陷，而是这类研究在当前数据条件下的通行做法。
