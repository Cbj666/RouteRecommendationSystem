# 前端原型规格

PPT 第 6 页那张图的**唯一真源**是 `frontend/reference/index.html`（可运行、1600×1000）。
本文把它的数值抄成表，方便用 Vue 重写时对账；两者不一致时以 `index.html` 为准。

> 一句话：**米白底 + 毛玻璃两块侧栏 + 按分数上色的路网 + 一条白描边黑环线**。
> 没有圆角，没有阴影堆叠，除了主色 `#15503C` 之外几乎没有第二种彩色。

---

## 1. 画布与色板

| 项 | 值 |
|---|---|
| 画布 | **1600 × 1000**（`overflow: hidden`） |
| 底色 | `#F5F8F2`（米白偏绿） |
| 主色 | `#15503C`（品牌、按钮、选中态、分数、条形） |
| 主色浅 | `#E7F1EA`（徽标底） |
| 正文 | `#1F2A26` |
| 次级文字 | `#5F6F68` |
| 弱文字 / 标签 | `#8A9A93` |
| 分隔线 | `#E6EDE9`（实线）、`#E9EFEC`（虚线） |
| 强调橙（坡度条） | `#C0762A` |
| 环线 | `#141414`，白描边 `#FFFFFF` |

字体：`"Microsoft YaHei", "PingFang SC", sans-serif`。数字一律 `font-variant-numeric: tabular-nums`。

毛玻璃（左右两块面板）：

```css
background: rgba(255,255,255,.74);
backdrop-filter: blur(22px) saturate(1.2);
border: 1px solid rgba(255,255,255,.9);
box-shadow: 0 14px 44px rgba(18,58,44,.13);
border-radius: 0;   /* 关键：不要圆角 */
```

## 3. 组件规格

**品牌**：方块 22×22 `#15503C`，内部挖 6 px 白（`::after{inset:6px;background:#fff}`）；字 19 px / 700 / `letter-spacing .5px`。
**Tab**：padding `7px 16px`、15 px；选中态底色 `#15503C`、白字、600；未选中 `#5F6F68`。
**搜索框**：宽 300、`padding 8px 18px`、14 px、`#8A9A93`、边框 `#E2EAE5`、底 `rgba(255,255,255,.6)`、靠右。

**起点卡**：`pin` 26×26 `#15503C` 白字「起」；标题 16 px；坐标 12.5 px `#7E8E87`；整块下边框 `1px solid #E6EDE9`、`padding-bottom 18`。
**分段按钮**（模式 / 距离）：`flex` 等分、`gap 8`、`padding 9px 0`、14 px、边框 `#DFE8E3`；选中 `#15503C` 白字 600。
**开关**：轨 42×22、`#D7E0DA` → 选中 `#15503C`；滑块 16×16 白、`left 3` → `left 23`、`box-shadow 0 1px 3px rgba(0,0,0,.2)`；每行 `padding 11px 0`、下边框 `1px dashed #E9EFEC`。
**主按钮**：通栏（左右各溢出 22 px 贴到面板边缘）、`#15503C`、`padding 17px 0`、16 px / 600 / `letter-spacing 1px`；副行 11.5 px `#BFD8CC`。

**分数**：54 px / 700 / `#15503C` / `letter-spacing -1px`，`line-height .95`；`/ 100` 为 15 px `#8A9A93`；徽标 `#E7F1EA` 底 + `#15503C` 字 12.5 px。
**六宫格**：两列、`gap 1px`、底色 `#E6EDE9` 当分隔线、格子底 `rgba(255,255,255,.86)`、padding `12 12 13`；标签 11.5 px `#8A9A93`，数值 18 px / 600。
**子分条**：三列 `74px 1fr 32px`、行距 11；轨道与填充都高 7 px，轨道 `#E3EAE6`、填充 `#15503C`（坡度那条用 `#C0762A`）；数值右对齐 600。

**图例**：标题 12 px / 600；色带宽 118 × 高 8；刻度 10.5 px `#8A9A93`（30 / 50 / 70 / 85）；环线示意 14×3 的 `#1B1B1B` 短线 + 文案。

## 4. 文案（照抄，别改写）

- 品牌：`跑步友好度 · 武汉`
- 顶栏 tab：`适宜性地图`（选中）/ `环线推荐` / `起点对比`
- 搜索框：`搜索起点：东湖绿道 / 珞珈山 / 江滩…`
- 左栏：`起点`、`武汉大学 · 八一路珞珈山`、`114.3547, 30.5342`、`路线模式`、`环线` / `单行线 A→B`、`目标距离`、`3 km` / `5 km` / `10 km`、`偏好`、四个开关（`尽量绿荫 / 滨水`、`避开机动车主干道`、`尽量平坦`、`洗手间 / 补给点`）
- 按钮：`生成路线` + 副行 `环线：半程折返 + 回程双向惩罚`
- 右栏头：`环线 · 第 1 条　回到起点`
- 六格：`距离 / 预计用时 / 树冠覆盖 / 平均坡度 / 最近场馆 / 起点偏差` → `5.34 km / 32 min / 58% / 3.5% / 240 m / 2 m`
- 三条：`安全 84`、`绿化与滨水 81`、`坡度平缓 65`
- 权重句：`环线由「半程折返 + 回程边罚」生成；综合分按 安全 0.25 / 绿化 0.25 / 坡度 0.15 / 过街 0.10 / 空气 0.15 / 设施 0.05 加权。`
- 图例：`慢跑适宜性`、`推荐环线 5.34 km`
- 页脚：`数据来源：OSM 路网 · SRTM 30 m 坡度 · ESA WorldCover 10 m 树冠 · CHAP 1 km 空气 · 高德场馆 POI`

## 5. 数据从哪来

| 界面位置 | 字段 | 来源 |
|---|---|---|
| 左栏四个开关 | — | 用户输入，映射到 `POST /api/loops` 的 `prefs {green, safe, flat}` |
| 右栏大分数 | `score` | `loops.features[0].properties.score` |
| 距离 / 用时 | `length_m`、`minutes` | 同一条 feature |
| 树冠 / 坡度 / 场馆 / 偏差 | `tree_share`、`slope_mean_pct`、`facility_m`、`origin_snap_m` | 同一条 feature |
| 三条子分 | `JSON.parse(props.sub)` → `s_safety / s_green / s_slope` | 注意是**字符串**，要 parse |
| 路网颜色 | `segments_city.geojson` 的 `score` | 前端直接从 `data/output/running/v1/web/` 读 |
| 环线几何 | `geometry.coordinates`（WGS84） | 用百度地图要转 BD-09 |

## 6. 验收清单

对着 `presentation/前端原型图.png` 逐条打勾：

- [ ] 画布 1600×1000，底色 `#F5F8F2`，**没有任何圆角**
- [ ] 顶栏高 64，品牌方块是「绿底挖白心」而不是圆点
- [ ] 左栏宽 306、右栏宽 330，与地图边缘各留 24 px
- [ ] 路网按 `t = (score-30)/42` 上色，整体偏绿、只有主干发橙
- [ ] 环线是「白描边 + 黑实线」两层，不是单层黑线
- [ ] 大分数 54 px、`#15503C`、带 `/ 100` 与「很适宜」徽标
- [ ] 六宫格用 1 px 底色缝分隔，不是边框
- [ ] 图例色带五档、刻度 30/50/70/85，右下角与右栏留 380 px
- [ ] 页脚那行数据来源完整
