## 1. 做了什么

基线权重：安全 0.30 / 绿化 0.25 / 坡度 0.20 / 过街 0.10 / 设施 0.10。

| 场景 | 含义 |
|---|---|
| `*_+80%` / `*_+120%` | 单维度权重 ×0.8 / ×1.2，其余按比例归一 |
| `alt_equal` | 五维等权 |
| `alt_ahp_like` | 安全 0.35 的 AHP 式方案 |
| `alt_terrain_first` | 坡度 0.40 |
| `alt_comfort_first` | 绿化 0.35 + 坡度 0.30 |

评价指标：与基线的 **Spearman 秩相关**、**前 10% 路段重合度**、均值偏移。

---

## 2. 第一版结果

| 场景 | Spearman | 前 10% 重合 | 结论 |
|---|---:|---:|---|
| 单维度 ±20% | 0.9954 – 0.9984 | 0.942 – 0.972 | **几乎不改变排序** |
| 等权 | 0.8894 | 0.663 | 排序明显变化 |
| AHP 式 | 0.9981 | 0.958 | 基本一致 |
| 地形优先 | 0.9029 | 0.799 | 中高分段重排 |
| 舒适优先 | 0.9427 | 0.828 | 有变化但结构稳定 |

**可以写进答辩的一句话**：

> 单维度权重上下浮动 20%，路段排序的秩相关仍在 0.995 以上，前 10% 重合度超过 94%，
> 说明结论对权重不敏感；只有当整体权重结构被替换（例如五维等权）时，排序才会明显变化
> （秩相关 0.889，前 10% 重合 66%）。
