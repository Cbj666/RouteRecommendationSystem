## 4. 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `缺少 data/raw/worldcover` | 没下 WorldCover | 按 `docs/数据/数据补充清单.md` 下载 4 幅 |
| `rasterio.errors.RasterioIOError` | 瓦片损坏 / 路径含中文 | 重新下载；确认路径 |
| `树冠全为 0` | 拼接错位（历史 bug） | 见 `AGENTS.md` 第 8 节第 1 条 |
| `pyosmium: The system cannot find the file` | PBF 路径含中文 | 复制到 `D:\tmp\` 再解析 |
| `FUEL: CUQPS_HAS_EXCEEDED_THE_LIMIT` | 高德限流 | 脚本会自动退避；间隔已设 0.45 s |
| `pytest: 找不到 segments.gpkg` | 没跑评分 | 先 `build_running_dataset.py` |
