## 写法约定

- 结论先写，数字必须有出处（脚本名 / 文件名 / 字段名）；
- 路径写相对仓库根目录的形式，例如 `data/processed/running/v1/segments.gpkg`；
- 提到限制就写清楚"不能说什么"（例：不能说评分等于真实跑步体验）。
