# 参考文献（working）

最后更新：2026-11-02　·　全文 PDF 在 `docs/literature/`（5 篇，均可打开）

用法分三档，写进 PPT 或答辩稿时**不要混用**：

- **依据** —— 我们的做法直接沿用它的结论/方法，可以正面写"参照 X"。
- **参考** —— 思路相近但不是同一件事，只能写"类似做法见 X"。
- **限制** —— 它证明的是我们的短板，只能写在"已知局限 / 后续工作"里。

## 一、中文文献（已下载全文）

### 1. 步行适宜性指标体系 —— 可写「依据」

> 刘信知, 孙帅. 北京北护城河及玉河沿岸空间步行适宜性评价[J]. 山西建筑, 2025, 51(12): 33–36. DOI: 10.13719/j.cnki.1009-6825.2025.12.008

- 做法：百度街景照片 + SPSS，**3 个一级指标（舒适性 / 安全性 / 景观品质）+ 7 个二级指标**，评价两条滨河步行路。
- 支撑：P8「多指标加权 + 分层指标」在国内有直接先例；它的一级指标可与我们的安全、绿化、坡度对上。
- 注意：它靠街景取数，我们拿不到街景 API，**不能写"采用同样方法"**，只能写"指标分层方式参照"。

### 2. 设施可达性 —— 可写「依据」（用于批评现状）

> 何丽波, 李文君. 基于高斯两步移动搜索法的长沙市主城区适老公园绿地可达性研究[J]. 湖南包装, 2026, 41(4): 79–84. DOI: 10.19686/j.cnki.issn1671-4997.2026.04.019

- 做法：高斯两步移动搜索法（Ga2SFCA），按老年步行速度与出行阈值设衰减；结果显示"中心集聚、外围递减"，正向因素是**公园密度、路网连通性、人行道覆盖率**。
- 支撑：P8 设施维度那句"**传统可达性 = 最近距离，这是不够的**"可以正面引它；也是我们把 `s_fac` 从"最近场馆距离"升级到 2SFCA 的路线依据。
- 注意：**我们并没有实现 2SFCA**，只能说"识别到问题 + 给出了升级路径"。

### 3. 绿化维度 —— 只能写「限制」

> 高时雨, 骆杰轩. 基于街景与卫星影像的城市街道绿化特征分析[J]. 北京测绘, 2026, 40(10): 1424–1429. DOI: 10.19580/j.cnki.1007-3000.2026040003

- 做法：广州越秀 514 个街道单元，卫星提植被覆盖率 IFVC、街景提绿视率 IGVI。
- 关键数字：**IGVI 均值 0.153**；**IFVC–IGVI 相关系数 r = 0.617（P<0.01）**，即二维覆盖率与三维绿视"整体正相关、局部显著背离"。
- 支撑：**这是我们 `tree_share` 短板最硬的定量证据**——卫星树冠覆盖率和行人实际感受到的绿意只有 0.62 的相关。写在 P8 局限或 P9 讨论里非常合适。
- 注意：不要写"我们做了绿视率"。我们没做，也没有街景 API。

### 4. 指标体系与定权 —— 可写「依据」（但别说是我们的做法）

> 吉实. 片区尺度的城市建成环境健康适宜性评价方法研究[D]. 北京建筑大学, 2025.

- 做法：提出"健康资源—健康公平—健康风险"三维框架；**文献分析 + 专家咨询 + AHP** 筛出 17 项指标并确定权重；POI + 遥感 + 问卷多源数据 + GIS 空间分析。
- 支撑：P9 调参页可以引它说明"**AHP + 专家咨询是规划领域定权的通行做法**"，我们的权重构成不是拍脑袋。
- 注意：**我们没有真的跑 AHP**（是人工权重 + 16 组敏感性检验）。写"参照 AHP 的思路分层，用敏感性检验替代一致性检验"。

### 5. 加权线性组合 —— 可写「参考」

> 吕梦琦, 王岳颐. 适宜性评价模型在闲置铁路空间再生中的应用[J]. 世界建筑, 2025.

- 做法：加权线性组合法，从生态、文旅、交通、社会四个层面建适宜性模型，评价京西 4 条铁路闲置空间。
- 支撑：P8"加权线性组合 + 分层指标"的表述先例；也在 P12 说明"这套评价框架可以迁移到别的场景"。

## 三、引用口径（答辩前必看）

1. **过街反向是主动分歧，不是错误**。Frank 等人的步行指数里交叉口密度是正向（利于连通），我们做负向（跑步要连续）。讲的时候先承认它是正向指标，再说明"步行服务到达、跑步服务连续"，并说明这是待验证假设。
2. **2SFCA 没实现**。设施维度现在是"到最近场馆的指数衰减"，2SFCA 写在下一步。
3. **绿视率没做**。没有街景 API，用第 3 篇的 r = 0.617 说明"这是已知局限，不是没意识到"。
4. **AHP 没跑**。权重是人工定的，检验手段是 16 组敏感性分析（Spearman ≥ 0.9940），不是一致性比率 CR。
5. 所有英文文献的卷期页码已与 OpenAlex 核对；**未经核对的引文不要写进 PPT**。
